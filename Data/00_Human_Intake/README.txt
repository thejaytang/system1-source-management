MANUAL SOURCE INTAKE

Drop new PDF, HTML, XLSX or ZIP source candidates directly in this folder.
Do not rename or move files after starting the intake process.

Then run Code/scripts/08_scan_manual_intake.command, or run the normal review
cycle. The program will extract basic metadata and embedded official links,
prefer an equivalent official HTML source over PDF, and create a candidate in
Human Operation Desktop. A human must complete missing fields and choose ACCEPT
or REJECT. ACCEPT does not imply final legal or project applicability approval.

Do not place passwords, API keys or unapproved confidential material here.
